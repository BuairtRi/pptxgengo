# Local composition example

Audience: maintainers and presentation authors using the current v5 diagram adapters.

Purpose: demonstrate reusable deck-local designs for a three-circle Venn, a numbered maturity curve with a current-position flag, and a numbered winding road.

All slide copy, labels, numbers, synthetic dates, active states and diagram data are maintained in deck.yaml. No real client assessment, schedule, outcome or evidence is implied. Build and native review are required for each authored use.

# Candidate local composition example

Audience: maintainers and presentation authors evaluating the incoming v4 diagram adapters.

Purpose: demonstrate three reusable deck-local designs using the same Go planners as shared templates. The pages cover a three-circle Venn, a numbered maturity curve with a current-position flag, and a numbered winding road.

All slide copy, labels, numbers, synthetic dates, active states and diagram data are maintained in `deck.yaml` slide values. Reusable definitions contain their allocation, style, supported topology, binding rules and stable item keys. No real client assessment, schedule, outcome or evidence is implied.

The example targets the frozen 522-template v4 candidate. V4 is unreleased. Native visual qualification and installed activation are pending. The separate upstream 587-template observation does not change this example's intended source pin.

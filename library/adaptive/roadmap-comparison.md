# Adaptive roadmap and comparison examples

These fifteen JSON files contain **synthetic content**. They exercise changing data counts, long copy, and semantic style variants. They are inputs to `pptxadapt compile`, which creates a `pptxgengo.compose-spec.v1` file for the measured compose workflow. A successful compile or probe does not establish text fit or visual acceptance.

## Roadmap

`family` is `roadmap`. `content.periods` contains 3–12 ordered `{id,label}` entries. `content.workstreams` contains 1–8 rows with unique IDs, a label, optional phase `group`, a required row `status`, one or more intervals, and optional milestones. Each interval names inclusive `start_period` and `end_period` IDs and an explicit `status`. Milestones name one `period` and a label; optional `caption_periods` reserves 1–3 period widths for the caption and defaults to 1. A one-period caption is centered under its star. Long-copy captions should explicitly reserve 2 or 3 periods and still require native fit review. Status is one of `planned`, `active`, `complete`, `at_risk`, or `blocked`. Intervals within a row may not overlap; a period outside every interval remains off. Rows and period cells stay editable.

The adapter uses the period grid and phase bands of T015 and the swimlane/milestone vocabulary of T039. Each workstream row has a shared activity lane: the workstream label, interval bars, and milestone stars have the same vertical centerline. The caption lane sits below it, so captions can span nearby periods without covering duration shading. The activity lane reaches 31 points when space permits, accommodating a measured two-line 11-point workstream label; dense rows retain a 16-point caption frame at the supported minimum 35-point row height. Milestone captions use `min(label_font_pt, 10)` points as a fixed visual hierarchy limit; this is independent of caption length and is not automatic text fitting. `active` and `at_risk` share the default blue fill; `complete` and `blocked` share the default navy fill. The workstream label spells out its row status, but individual interval statuses are **not uniquely encoded by color** when these pairs occur in the same row. Distinct interval statuses need additional labeling or a separately qualified style before client use. The adapter does not infer dates, task dependencies, or a plan from prose. Every text frame goes through the native compose measurement and fit workflow before use.

## Comparison

`family` is `comparison`. `content.options` contains 2–4 unique `{id,label}` entries. `content.criteria` contains 1–7 rows. Each row has a label, one criterion-level `gauge`, and one `finding` for every option; the gauge is not a score for each option. A gauge requires numeric `value`, `scale_min`, `scale_max`, `target_min`, and `target_max`, with optional `unit`. All values must lie within the scale and the target minimum cannot exceed the target maximum. The exact numbers position an actual-value needle and target band. Findings contain `option_id`, nonempty `text`, and `status`: `strong`, `mixed`, `limited`, or `unknown`. These statuses color the finding cells and are named in the legend; the adapter does not derive them from the numeric gauge.

The adapter uses T045's pale comparison cells, navy headers, and gauge emphasis. `content.gauge_mode` defaults to `linear`; `dial` draws an editable native block-arc base, target sector, and rotated triangle needle from the same supplied values. Every gauge shows its supplied scale and target range in **fixed 9-point** editable text, and the four-status swatch legend also uses fixed 9-point labels in a 12-point strip below the comparison body. These sizes are hierarchy choices, not content-dependent autofit or `label_font_pt` overrides. If `target_min == target_max`, the numeric target remains visible but there is no zero-width target band or sector. Rows need at least 45 points; dial rows need at least 58 points, so dense seven-row fixtures stay linear. The adapter does not score evidence or invent numeric values. Long numeric labels and finding copy require native measurement and visual review.

Fixtures with `few`, `normal`, `more`, `long`, `style`, and `inverse` suffixes cover both families; comparison also has `dial` and `dial-inverse`. The `style` variants use the supported `subtle` profile; `inverse` exercises the dark profile. The inverse dial fixture varies target ranges by criterion to exercise target-sector geometry. `comparison-illustrative.json` shows a hypothetical modernization choice across three options and five criteria, using explicit illustrative ratings on a 0–5 scale. All fixtures are illustrative and should be replaced with sourced client facts before client use.

# Template changes since the pptxgengo snapshot

Generated by `tools/template_changes.py` from `templates/library` against `pptxgengo-wmds-v1` (commit `d8f45d4`),
the snapshot pinned by pptxgengo `library/wm-design-system/v1`. Machine-readable copy: `templates/changes.json`.

Summary: 70 added, 15 revised, 1 deprecated, 0 removed.

## Frames and renderer

### splits

New split-frame family: the title zone covers a short column only and a tall column runs from y 36 to the body bottom. Four variants: tall-right, tall-left (tall two-thirds, 558 wide) and tall-right-narrow, tall-left-narrow (tall one-third, 270 wide); standard 18 pt gutter (narrowed from a one-column gutter on owner review).

**PowerPoint:** Add four slide layouts (or a split option on the existing no-rail and nav layouts): header placeholders sized to the short column; a 270-wide short column sets the title at heading size (24/30) with up to three lines (rule at 108/126/162), a 558-wide one keeps title size (rule 108/144/180). The header dot patch starts 36 pt left of the short column (not left of x 57 on nav). Stamp and source line follow the short column.

### nav

Nav-rail tabs are now slots: slide.nav = {items: [2-6 section names], active: index}. Previously the labels were hard-coded (Identify, Define, Build, Optimize) with the second always active. Split frames now combine with the nav rail.

**PowerPoint:** Read tab labels and the active tab from slide.nav; tab height = (body bottom - 36 - 6*(n-1)) / n; active tab Grounded with White text, others Light Gray with Dark Gray text. No template used the nav rail before, so this only affects new templates.

### quadrant-markers

Quadrant chart gains key: "markers": numbered filled circles on the points without the built-in key, for templates with their own legend column.

**PowerPoint:** Support key "markers" on the quadrant chart: draw numbered circles at each point and omit the side key.

### table-checkbox

Table cell type checkbox: an empty outlined box for walk-through checklists (true draws a tick). Distinct from check, which reports status (filled tick or dash).

**PowerPoint:** Support cell type checkbox: 12 pt square, 1 pt Grounded outline, no fill; a tick when true. Used by runbook/step-detail-data and runbook/step-detail-gate.

Changed keys in `frames/v0/frames.json`: splits.

# wm-design-system

A personal West Monroe design system for Claude Design and for native, editable
PowerPoint generated by the sibling `pptxgengo` repo. This repo defines the design;
it never writes .pptx.

- `tokens/v0/tokens.json`: foundations (colors, surface roles, type styles, grid with the 5-up exception, spacing, number formats)
- `components/v0/components.json`: primitives, components and composites (layer-tagged), card system, ink rules, examples
- `frames/v0/frames.json`: slide master and layouts (rail × footer), required chrome (legal line, whiteboard grid), zones
- `templates/library/<family>.json`: the slide templates, one file per family
- `templates/catalog.json`: generated index of every template (`tools/build_catalog.py`)
- `docs/authoring-reference.md`: geometry, node types and rules for writing templates; `docs/icons.md`: icon names
- `explorations/components.src.html`: the reference board (Overview, Foundations, Primitives, Components, Composites, Frames, Templates)
- `docs/claude-design/`: hand-written sources for the Claude Design bundle's `SKILL.md` and `README.md`
- `tools/`: `build_explorations.py` (board, embeds assets from `~/Documents/branding`), `build_catalog.py`,
  `build_design_bundle.py` (Claude Design bundle into `build/claude-design/`, uploaded with `/design-sync`),
  `check_templates.py` (rules), `render_template.py` (headless PNG of any template)

Build: `python3 tools/build_explorations.py` (outputs `explorations/components.html`, git-ignored).
Check: `python3 tools/check_templates.py && python3 tools/build_catalog.py --check`.

# Icon names

The brand icon library (`~/Documents/branding/icons`, 222 icons). Use the name in any `icon` field, e.g. `"icon": "security-shield-lock"`.
Each icon is a 72 × 72 square with its own frame. Inks: Grounded on White and the light grays, Magenta for one highlighted icon, White on Grounded and Deep. No other colors.
Slide sizes: 36, 54 or 72 pt. The older short names `people`, `layers`, `chart`, `monitor`, `server`, `database`, `clock`, `shield` and `target` still work.

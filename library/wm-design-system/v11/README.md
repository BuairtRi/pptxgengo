352 source specimens have fresh full-size native PowerPoint reviews. The other
297 retain accepted previews after exact authored composition and visible
dependency comparisons. All 649 source builds and 648 active bound builds pass.
Stock qualification does not qualify edited copy; each edited deck needs fit
and native visual review.

Density follows the designer's role scales across the entire slide body:
Comfortable, Compact or Dense. Headers stay Comfortable unless explicitly set.
Automatic fitting steps down the body tier with CLI warnings; it never changes
the header tier or the authored outer geometry. Set `auto_density: false` to
keep the requested tier. Ten introductory templates allow Comfortable only.
The source owns those limits; YAML cannot relax them.

All 1,927 supported density configurations pass contrast checks. Twenty
prohibited configurations are recorded as unsupported. Small accent labels use
the approved Blue/Grounded treatments, while fixed circle and tile numerals
retain their defined sizes. The 312 native typography controls and historical
source isolation have independent regression evidence.

The package contains one production library. Historical source pins remain
under `planning/wm-design-contracts` for reproducibility. Intake metadata is
preserved; native acceptance is recorded by the published gallery and its
retained review packets. Released documentation uses the same exact source pin.

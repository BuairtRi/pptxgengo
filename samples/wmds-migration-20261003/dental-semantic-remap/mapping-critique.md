# DentalXChange semantic remapping

All 57 original native slides and 32 catalog candidate specimens were individually inspected for this pass. The discovery index includes the accepted PowerPoint gallery; preview paths and hashes are verified. No original or prior conversion source was edited for this plan.

The proposed deck uses 25 catalog families. The current deck had preserved source content and passed native fit review, but several parent selections did not match the purpose: metric cover, calendar roadmap, roles-by-phase, and priced service-value layouts were used for content with different meaning.

The new maintained project will use actual catalog visual structure and styles, with limited derivatives for truthful source counts and roles. The default remains 57 slides. Speaker notes, original hidden flags, seven native sections, original media and chart data remain traceable; visible prose can be reshaped while facts and qualifications remain available in notes.

## Main changes

- PDLC phase coverage: `intellio/swimlane`, retaining sequential and parallel spans, decisions, six phase labels and source rules.
- Discovery participants: neutral roster, preserving all names/functions and the original collaborative-session photograph.
- Maturity evidence: native categorical grids with named source statuses and caveats; no invented numerical scale.
- Recommendations: two explicitly labeled groups of three; engineering activation uses Now/Next/Future.
- Action registers: ruled operational tables with exact source column meanings, owners, dependencies and measures.
- Artifact ownership: native ownership grid with original L/C/A or L/C/I/A meanings; the RACI preset's fixed legend is unsuitable without adaptation.
- Workstream proposals: actual catalog four-activity offer structures; combined pricing remains explicitly for all three workstreams.

The JSON contains a separate purpose, critique, primary/alternate candidate, exact preview path/hash, component zones, adaptation and preservation rule for every source slide. These are semantic proposals; supplied-content fit and native review follow the new build.

## Discovery and authoring friction

The gallery-backed unified index resolves all 32 inspected previews. Before the ranking update, capped text scores saturated after two terms, tying unrelated purposes. Structure filters and manual contract inspection were necessary. Root supplied an updated ranking/summary binary.

The existing detach command validates and builds the whole deck before extracting a local template, refuses typed cardrow templates and stamped/source-note chrome, and requires exact source cardinality first. A public scaffold from catalog definition plus stable semantic bindings would make six-step or nine-row derivatives straightforward without rebuilding legacy shapes. Batch id-keyed template/value patches are also useful. No new Python helper is needed.

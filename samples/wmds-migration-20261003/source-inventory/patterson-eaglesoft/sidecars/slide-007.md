West Monroe recommends 2 goals for this modernization effort: aligning Eaglesoft to a classic 3-tier architecture and modernizing the user interface stack

OUR PERSPECTIVE

West Monroe recommends taking a user-journey focused approach to the modernization program. But identifying and prioritizing user journeys, we can align the modernization and testing strategy approach to ensure that changes are desirable, performant and validated.

VISION FOR THE FUTURE

CURRENT STATE
PowerBuilder supports a practice-local application where the user experience, business behavior, and data access have grown together.
The user experience remains tied to a legacy desktop runtime.
Business rules and transaction behavior span UI code and direct data paths.
Device and partner dependencies shape each journey transition.
Screen-only replacement preserves the existing business and data coupling.

An independent application foundation

Outcome
An independent user experience, reusable business operations, governed data access, and a clear path to PowerBuilder retirement.

7

POWERBUILDER RETIREMENT
PowerBuilder has become a niche, legacy application stack. West Monroe recommends modernizing to a web-based user interface layer to ensure Pattern can continue to hire skilled engineers, to support a potential SaaS-ification of the product, and alignment with potential desktop and mobile deployment capabilities.

THREE-TIER RESPONSIBILITY
Modern application architecture practices over the last 15 years recommend a 3-tier structure: data access, service/domain, and user interface to ensure each layer can be maintained and upgraded separately. West Monroe recommends aligning to this high-level approach as an outcome of the modernization.

WEB EXPERIENCE ON PREMISES
React provides browser or PWA delivery within the practice network. Embedded and desktop routes remain transition choices. WAN network support could potentially allow multi-site expansion for practices with that network capability.

JOURNEY-LED DELIVERY
By using a journey-led approach, the disruption inside individual critical user journeys is minimized. Piloting specific personas or roles holistically can create a more seamless transition experience for customers. In addition, end to end testing for specific flows can be aligned with the testing workstream.

OUR UNDERSTANDING
Patterson is seeking to modernize Eaglesoft by creating a reusable data and API layer, upgrading selected PowerBuilder and UI workflows, and building automated performance testing to ensure the product remains reliable

What We Heard
Eaglesoft is a desktop dental practice management platform built mainly on PowerBuilder
PowerBuilder code still accesses SQL Anywhere directly through embedded SQL, DataWindows, dynamic SQL, and transaction logic
Rules are distributed across the UI, application code, database queries and stored procedures, making change and testing difficult
A working PostgreSQL environment already exists, so the primary need is architectural decoupling and modernization
The platform needs a reusable service and API foundation that supports current desktop modernization while preserving options for future browser or SaaS development

Desired Outcomes
Establish a reusable service and data layer that modernizes the UI and implements a 3-tier architecture to decouple UI logic from direct data access without destabilizing the current product
Initiate an incremental modernization of priority workflows and selected UI experiences
Build automated full-stack performance testing, telemetry, and release gates to validate performance across the desktop, APIs, services, database, and infrastructure
Develop a maintainable platform with a path toward future browser or cloud capabilities

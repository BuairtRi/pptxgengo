Client specializes in drug testing, employee background and occupational health screening, transportation compliance, and substance abuse training. Their dated monolithic architecture results in large, risky releases and presents challenges in upgrading specific domains.

Workplace Safety & Compliance Provider

How can we expand our occupational health offering while modernizing our architecture?

Modernization Strategy & Build
Performed an initial architecture deep dive phase to identify pain points and formulate an approach ahead of the build phase
Streamlined the implementation approach by instituting a more Agile design and development process than that of other vendors, significantly lowering the time to produce working, high-quality code
Split the occupational health domain apart from the on-prem monolithic back-end by creating a new .NET Core microservice and SQL database hosted in Azure
Currently revamping their current internal-facing and client-facing experiences, replacing ASP.NET web pages with React in the process
Will leverage Azure Data Factory to perform a one-time data migration to retire occupational health data in the legacy on-prem SQL Server database and have the Azure SQL database become the source of truth, updating downstream systems to pull from the new microservice

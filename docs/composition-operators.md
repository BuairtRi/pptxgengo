## Source mutation contract

Templates are customizable examples, not fixed organizational or timeline facts.
Family operators edit typed source models while retaining the selected frame,
grid and provenance. Each patch names an actor/reason and current authored-source
SHA256. Preview compiles and measures the full candidate without writing source.
Apply repeats validation inside a source transaction that checks all predecessor
bytes and retains a decision receipt. Shared/pinned local definitions and active
native geometry/order are refused until explicitly resolved.

Bindings are not silently discarded. The selected component can be explicitly
materialized into a local definition; resolved copy becomes local template
constants and only now-unused bindings/zones are removed. Stable collection keys
are persisted before reorder/reassignment. YAML comments on nested nodes follow
stable identities rather than array positions. A failed/stale/oversized candidate
leaves authored files unchanged.

Gantt coordinates are numeric periods, not an inferred calendar. Gate emphasis
uses an optional callout independently of string identity; legacy boolean gates
retain their meaning. Optional `icon: none` omits a lane graphic without requiring
private graphical assets or changing the label allocation. Explicit compact
legend/layout options support local derivatives without weakening frame checks.

Native import requires both authored-source and input-PPTX hashes plus the
explicit `reauthor_with_design_style` policy. It selects unique top-level
unrotated rectangular plain-text shapes by exact part/name. Imported text,
alignment and design-system styling are explicit; imported nodes do not acquire
family semantics by appearance. Original package bytes are retained in the
content-addressed global asset store and the map/observations in the decision.
Full project sharing must preserve those private source materials.

## Native edit boundaries

Existing receipt-backed text and geometry reconciliation remains separate from
semantic composition. Moving a pod role does not establish a new pod membership;
moving an org-chart node does not reparent it; resizing a task does not retime it.
Unsupported copied bars, subshape deletions and imported SmartArt remain review
findings. Explicit family patches persist the operator's confirmed meaning.

The import slice does not preserve foreign shape formatting or import general
rich/native objects. The family slice does not add arbitrary graph routing,
critical-path scheduling, staffing curves or all catalog-family operators.
[Semantic template audit](template-customization-audit.md) and
[routing backlog](geometry-routing-backlog.md) retain that next work.

## Qualification

Focused source tests cover catalog-derived pod and Gantt changes, stable keys,
bindings/materialization, topology/cycles, invalid operations, stale source,
capacity refusal and guarded source preservation. Native-export tests cover
streaming helper phase evidence and cancellation. Desktop evidence is specimen
specific; Go fit and fake-runner tests are not native PowerPoint qualification.

Record exact native review inputs/results separately. Windows desktop
qualification, arbitrary native imports and external GUI transport root causes
remain outside these source-test results. See the
[PowerPoint failure catalog](powerpoint-automation-diagnostics.md) for tested
code fixes versus observed recoveries and unresolved causes.

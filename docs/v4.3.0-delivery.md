# v4.3.0 semantic composition delivery

The [completion matrix](v4.3.0-completion-matrix.json) tracks every family in the
frozen V11 runtime: **649 templates, 29 families and 34 overlapping composition
profiles**. Implemented operators, actual-model companion routes, measured guards
and skill runbooks have named source evidence. All 29 customized family
representatives and all 11 full-source layer/curve adaptations passed actual
macOS PowerPoint Save As, native PDF export and independent visual review.
Profile assignments do not establish uniform models or desktop acceptance of
every catalog variant.

Source integration and release verification are still in progress. No v4.3.0 release has been published from this work yet.
Windows PowerPoint qualification is deferred to v4.4. Reusable content-complete
slides and external branding/photo distribution remain excluded; the template
browsing deck remains included.

## Native evidence and operational limits

The ledgers distinguish source authoring, controlled XML preparation, actual GUI
edits, actual GUI Save As and actual AppleScript Save As. They retain immutable
baselines, runtime pins, save hashes, review packets, explicit decisions, rebuilt
outputs and native PDF hashes. Acceptance is limited to the named inputs and
methods. A native open or a passing source test alone establishes neither semantic
adoption nor arbitrary import support.

Native review found and corrected real defects: decorative backings populated
with text, oversized schematic accents, table section reversal, numbered process
reversal, stale financial/maturity claims, rounded chart facts, curve-caption
collisions and an architecture header wrapped into an icon. Failed predecessors
remain retained rather than being reported as successful qualification.

PowerPoint recovery now has specific observed workflows in the
[failure catalog](powerpoint-automation-diagnostics.md) and
[operator runbook](../skills/west-monroe-presentations/references/powerpoint-recovery.md):
use a stable owned Documents folder and approve the exact document-access prompt;
rebind an exact renamed presentation after Save As; explicitly save/close chart
data before PowerPoint Save As and check both workbook and chart cache. GUI
capture, Apple events, filesystem access and document access remain distinct.
The cause of intermittent ScreenCaptureKit `-3811` is unconfirmed; recovered
capture does not establish a global permissions fix.

## Integration and private release

One final slotctl manifest preflight will precede submission and merge. GitHub
remains source review/merge authority; **all CI jobs and release artifacts are in
private GitLab**. Normal PR/main lanes stay light. Full catalog, race and desktop
work uses agreed nightly/on-demand lanes; tags run the packaging/signing/security
and installation gates without race tests or unavailable Windows GUI tests.

The [release checklist](../release/v4.3.0-checklist.md) requires the exact mirrored
main commit, protected immutable tag, successful private pipeline and independent
download verification. Final tagged resource generation includes the updated CLI,
V11 SQLite/templates, regenerated template browsing deck, registered SVG originals,
fonts and current Codex/Claude skill installation/update materials. Local resource
rehearsals are source evidence, not published artifact verification.

# Process and journey composition scope

Implementation checkpoint for the v4.3.0 development slice; qualification is
tracked separately from command availability.

- `project process` owns a new keyed typed process graph, actor lanes, explicit
  columns, named decision outcomes, joins/loops, start/current/end markers,
  incident-link deletion and measured source transactions.
- `project journey` wraps the existing native road/roadfork renderers. All source
  copy/geometry options are retained, current/chosen indices become stable keys,
  and lowering rewrites positions atomically after reorder.
- Fork trunk safety limit increases from three to twelve; existing renderer text
  and allocation checks remain authoritative. A large limit is not a fit claim.
- Process routing recalculates boundary endpoints and supports explicit local
  intermediate waypoints. Default orthogonal paths are not an obstacle-routing
  qualification; retain source review on every topology/layout change.
- Existing stock components are immutable. Process initialization requires a
  complete explicit model replacing a selected local rectangular leaf, with
  cascade acknowledgement. It neither imports arbitrary objects nor interprets
  geometry as process meaning.

## Source assignment audit

The maintained inventory has 15 process-graph, 44 sequence, six journey-road,
seven branching-journey, 36 roadmap-portfolio and 32 operational-procedure
assignments. Assignments overlap. Only `process/swimlane` is an actual typed
process in the process-graph set; the other variants include SIPOC, hierarchy,
current/future chevrons, metrics, workstreams, context and readiness composition.
Their semantic content must remain in coordinated native tables/cards/content;
converting every profile assignment into a graph would destroy its purpose.

Direct roads/forks use typed components in all 13 assigned variants. Tests load
those actual catalog source nodes and exercise inspection plus current-marker
preview with their stock allocations. Composed companion nodes need separate
qualification: node-only fixtures do not prove coordinated criteria/table edits
or the allocation of every complete split-frame slide.

Sequences use steppers, phases, Gantt, roles, metrics, cards and narrative. A
sequence can become an explicitly authored process when its intent is work and
outcomes; a phase table or role score does not become a graph automatically.
Operational-procedure assignments include checklists, contacts, RACI,
validation/UAT and progress tables; process routing applies specifically to
escalation and rollback-flow meaning. Family classification alone is not proof
of a successful native round trip or domain-specific semantic adoption.

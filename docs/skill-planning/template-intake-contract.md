## Future intake

Compare incoming definitions by canonical `id/variant` and complete values.
Family-file moves, gallery counts and changelog baselines are insufficient to
identify semantic additions or changes. Record source provenance and a complete
identity-level delta before creating another pinned source revision.

Existing source files, bundle manifests and accepted artifacts remain immutable.
Author a separate candidate, inspect its contracts and composition behavior,
build source and actual-content specimens, and review each native PowerPoint
page. Keep changed geometry, binding behavior and source content explicit.
Do not repurpose historical freeze scripts to overwrite the current source.

Discovery should expose scenario purpose, topology, editable slots, content
zones and verified previews. Agent selection must express the supplied content's
meaning. Count limits or successful compilation do not justify semantic changes
or certify fit. See [semantic discovery](../semantic-template-discovery.md),
[the source contract](deck-source-contract.md) and
[the catalog contract](catalog-discovery-contract.md).

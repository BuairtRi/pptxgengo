Windows preview: start with the core smoke test.
The binaries are cross-compiled for Windows; actual Windows execution and native PowerPoint export still need their first qualification run. PowerPoint COM export is experimental. If automation fails, open the generated deck in desktop PowerPoint and review it manually.

What you’re getting

  • Three CLI executables, the West Monroe presentations skill, IBM Plex fonts and documentation.
  • All 649 template definitions, a searchable SQLite index and source slide previews.
  • An editable YAML workflow with one file per slide, stock template bindings and retained build versions.
  • Density presets, PowerPoint sections and dividers, internal draft review notes, and client/maintainer export.

The smaller tester ZIP includes photography metadata and thumbnails. The full ZIP also includes the original photograph files. Both support authoring without installing Go or Python. Installing the skill here targets Codex; this package does not install a skill into the ChatGPT app.

Browse the design system

Run pptxgengo catalog --design-system --open to open the template specimen gallery. For the documentation site, run pptxgengo docs, keep that PowerShell window open, and browse http://localhost:8787/. Stop the server with Ctrl+C when finished.

# Web changelog

What changed in this repo that the wmds-web registry must implement. Newest first. Keep it current as work
happens, as with `templates/CHANGELOG.md` for pptxgengo.

## 2026-10-04 · heat map row notes

- `heatmap` gains `rowNotes?` (2-4 bullets per row), `rowRefs?` (reference badges such as A1) and `min?` (scale
  minimum, so 1-5 scores are stored as themselves). Mapped slide sections: Heat maps with row notes, Notes tied to a
  heat map. On the web, a row's notes open beneath it or in a side panel, and badges link overview rows to detail.

## 2026-10-03 · content vocabulary v0.1

- `team` and `proof` gain `source?`; a `proof` section may pass one case or a list.
- `heatmap` gains `cells?` linking each insight to the cells it refers to (0-based `[row, col]`).
- `maturity.current` and `target` are 0-based stage indexes.

## 2026-10-03 · radius

- `theme.css`: shadcn's whole radius scale (`--radius-xs` … `--radius-4xl`) maps to 0 so primitives stay square;
  `--radius-input` (2 px) is the only rounded corner, for inputs that opt in. `--radius-pill` stays for status pills
  and chips.

## 2026-10-03 · v0 web contract

- **Tokens**: `web/tokens/` added (`tokens.dtcg.json`, `tokens.css`, `theme.css`), generated by
  `tools/export_web_tokens.py` from `tokens/v0/tokens.json`. Includes shadcn semantic variables, `data-surface`
  scopes for the six slide surfaces, status and heat colors, and a proposed web type scale, spacing, radius, motion,
  focus and breakpoints.
- **Content vocabulary**: `web/content-types.json` with 14 types (ask, objectives, scope, approach, pricing,
  offer, roster, interview, findings, heatmap, maturity, team, metrics, proof). They map 230 of 587 slide
  templates. Reference: `docs/web/content-vocabulary.md`.
- **Architecture**: `docs/web/architecture.md` (layers, site manifest, frame-to-web mapping).
- **Web rules**: `docs/web/web-design-rules.md` (type, layout, states, motion, patterns, accessibility, chrome).
  Items marked Proposed await the owner's confirmation.
- **Implement first**: themed primitives; components status-pill, metric, section-header, heat-table, gantt,
  phase-stepper, person-tile; blocks ask-scqa, objectives-table, approach-gantt, approach-phases,
  pricing-options, interview-roster, interview-detail, heat-table, offer-hero; the proposal site template.
